# Лабораторная работа №1

В данной работе были изучены  базовые операции Apache Spark. Работа выполнялась в интерактивной среде Google Colab.

Для работы была создана SparkSession. Данные были загружены из CSV-файлов с автоматическим определением схемы (inferSchema).

Ниже представлено краткое описание проделанной работы.

## Решение задач
### Найти велосипед с максимальным временем пробега.
Для решения была применена группировка по bike_id и агрегация суммы длительности всех поездок.

*Результат:* Велосипед 535 набрал максимальное время 18611693 секунд.

### Найти наибольшее геодезическое расстояние между станциями.
Поскольку координаты заданы в широте и долготе, для расчета использовалась формула Гаверсинуса, учитывающая кривизну Земли

<img width="770" height="443" alt="image" src="https://github.com/user-attachments/assets/c1076632-6b85-44fe-87d0-8dc42d1ef14c" />

Был применен crossJoin таблицы станций самой с собой.

*Результат:* Максимальное расстояние составило 69.92 км между станциями SJSU и Embarcadero.

### Найти путь велосипеда с максимальным временем пробега через станции.

Используя ID велосипеда из Задачи №1, был отфильтрован список всех его поездок, отсортированный по времени старта.

*Результат:* Выведен хронологический список станций (первые 5), через которые проехал велосипед-рекордсмен.

### Найти количество велосипедов в системе.

Использован метод distinct().count() для колонки bike_id.

*Результат:* В системе зарегистрировано 700 уникальных велосипедов.

### Найти пользователей, потративших на поездки более 3 часов.

Поскольку в данных нет ID пользователя, идентификация проводилась по полю zip_code. Суммарная длительность поездок фильтровалась по условию >10800 секунд.

*Результат:* Найдено 20 почтовых индексов, суммарное время поездок по которым превысило 3 часа.
